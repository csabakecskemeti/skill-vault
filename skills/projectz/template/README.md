# My Projects

Personal project tracker powered by Markdown + Git.

## Quick Links

- [Project Index](./INDEX.md)
- [All Projects](./projects/)

## Setup

This repo works with the `/projectz` Claude Code skill. See [skill-vault](https://github.com/csabakecskemeti/skill-vault) for installation.

```
/projectz init <this-repo-url>
```

## Structure

```
├── INDEX.md           # Project overview (auto-updated)
├── computers/         # Registered computers
└── projects/          # Your projects
    └── <project>/
        ├── README.md  # Project info
        └── tasks/     # Task files
```
